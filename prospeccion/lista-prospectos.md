# Lista de prospectos

## Cómo usar esta lista
1. Busca en Google Maps el sector y zona
2. Filtra los que tienen web mala, desactualizada o no tienen
3. Rellena una fila por prospecto
4. Contacta ese mismo día si puedes
5. Actualiza el estado después de cada contacto

## Estados posibles
- 🔵 Por contactar
- 🟡 Contactado — esperando respuesta
- 🟠 En conversación
- 🟢 Reunión confirmada
- ✅ Propuesta enviada
- 💰 Cliente cerrado
- ❌ Descartado
